<H2> நற்பொருத்தங்கள் </H2> 
<ul> 
<li> நவீன மற்றும் இடைமுகத்தைப் பயன்படுத்த எளிதானது </li> 
</ul> 
<H3> அலாரங்கள் </H3> 
<ul> 
<li> தனிப்பயனாக்கக்கூடிய அட்டவணைகள் (தினசரி, வாராந்திர, குறிப்பிட்ட வார நாட்கள், குறிப்பிட்ட தேதிகள், தேதி வரம்பு) </li> 
<li> மெல்லிசை, உயரும் தொகுதி மற்றும் அதிர்வுகளை உள்ளமைக்கவும் </li> 
<li> உறக்கநிலை நீளம் மற்றும் அதிகபட்ச உறக்கநிலைகளை உள்ளமைக்கவும் </li> 
<li> அலாரம் பணிகள் (கணித சிக்கல்கள், ரெட்டைப் உரை, வரிசை, மேலும் வரவிருக்கும்) </li> 
<li> அலாரங்களை வடிகட்டவும் (அனைத்தும், இன்று, நாளை, உறக்கநிலை, முடக்கப்பட்டவை, நிறைவு) </li> 
</ul> 
<H3> கடிகாரம் </H3> 
<ul> 
<li> தனிப்பயனாக்கக்கூடிய கடிகார காட்சி </li> 
<li> உறவினர் நேர வித்தியாசத்துடன் உலக கடிகாரங்கள் </li> 
<li> நகரங்களைத் தேடிச் சேர்க்கவும் </li> 
</ul> 
<H3> நேரங்குறிகருவி </H3> 
<ul> 
<li> மெல்லிசை, உயரும் தொகுதி மற்றும் அதிர்வுகளை உள்ளமைக்கவும் </li> 
<li> நேரங்குறிகருவி முன்னமைவுகள் </li> 
<li> டைமர்களை வடிகட்டவும் (அனைத்தும், இயங்கும், இடைநிறுத்தப்பட்டு, நிறுத்தப்பட்டது) </li> 
</ul> 
<H3> ச்டாப்வாட்ச் </H3> 
<ul> 
<li> மடியில் வரலாறு மடியில் நேரங்கள் மற்றும் கழிந்த நேரங்கள் </li> 
<li> மடியில் ஒப்பீடுகள் </li> 
</ul 
<H3> தோற்றம் </H3> 
<ul> 
<li> பொருள் நீங்கள் கருப்பொருள்கள் </li> 
<li> மிகவும் தனிப்பயனாக்கக்கூடிய வண்ண கருப்பொருள்கள் </li> 
<li> மிகவும் தனிப்பயனாக்கக்கூடிய பாணி கருப்பொருள்கள் </li> 
</ul>
